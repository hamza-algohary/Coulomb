# Contributing to Coulomb

Thank you for your interest in contributing to **Coulomb**! 🎉  
All kinds of contributions are welcome, including code, design, documentation, and translations.

This document explains how you can get involved.

---

## Ways to Contribute

You can contribute in many ways, even if you are new to open source or programming:

### 🌍 Translations
- Help translate the project into **Spanish** or other languages.
- Improve existing translations.
- Report translation errors or unclear text.

### 🎨 Design
- Improve UI/UX ideas.
- Create or refine icons, layouts, or visual assets.
- Suggest design improvements.

### 💻 Programming
- Fix bugs.
- Implement new features.
- Improve code quality or performance.

> Beginner-friendly contributions are welcome. You don’t need to be an expert!
